# OBS Chzzk Alerts

치지직에서 새로운 팔로워가 생기면 OBS 화면에 팔로워 닉네임을 표시해 주는 Windows용 도구입니다.

현재는 **팔로우 알림만 지원**합니다. 구독과 후원은 치지직에서 제공하는 기존 알림 기능을 이용해 주세요.

## 베타 안내

**OBS Chzzk Alerts는 현재 베타 버전입니다.**

팔로우 알림은 치지직 공식 Open API가 아니라 스트리머 스튜디오 리모컨의 Socket.IO 이벤트를 감지해 표시합니다. 별도의 치지직 API 키는 필요하지 않지만, 치지직이 리모컨의 통신 형식과 호환성을 보장하지는 않습니다.

치지직 리모컨의 주소나 이벤트 형식이 변경되면 알림이 일시적으로 작동하지 않을 수 있습니다. 문제가 발생하면 [문제 해결](#문제-해결)을 확인하고 최신 버전으로 업데이트해 주세요.

## 주요 기능

- 치지직 신규 팔로우 이벤트 자동 감지
- 팔로워 닉네임을 OBS 전용 소스로 표시
- 원하는 PNG, JPG, WebP 이미지 또는 움직이는 GIF 함께 표시
- 이미지/GIF를 알림의 왼쪽·오른쪽·위·아래 또는 배경에 배치
- 이미지 크기·여백·불투명도와 원본 비율 유지 설정
- 새 알림마다 GIF를 처음부터 재생하는 옵션
- 기본 알림음 3종 또는 직접 고른 음원 재생 및 음량 설정
- 문구, 글꼴, 색상, 배경, 외곽선, 그림자와 정렬 설정
- 표시 시간, 페이드 인·아웃, 대기열과 중복 알림 방지 설정
- 설정 화면에서 즉시 확인할 수 있는 테스트 알림
- Chrome과 Microsoft Edge 지원
- 이벤트를 외부 서버로 보내지 않는 로컬 중계 방식
- 설치 프로그램을 통한 OBS 위치 자동 탐색 및 업데이트

## 0.5.0 업데이트 안내

- 기본 알림음 1·2·3을 바로 선택할 수 있습니다. 별도의 음원 파일을 찾지 않아도 됩니다.
- 직접 준비한 음원을 쓰려면 `사용자 파일`을 선택합니다.
- 알림음 선택 시 OBS가 종료되던 문제와 믹서에 알림 소리가 전달되지 않던 문제를 수정했습니다.
- 일반 탭과 팝업형 리모컨을 지원하며, 연결과 중복 알림 처리를 개선했습니다.
- 기존 알림 문구·이미지·GIF·장면 설정은 그대로 사용할 수 있습니다.

아래 설정 방법은 `0.5.0` 기준입니다. 이전 버전을 사용 중이라면 최신 설치 파일로 업데이트해 주세요.

- [Windows x64 설치 파일 바로 다운로드](https://github.com/TereBin/obs-chzzk-alerts-releases/releases/download/v0.5.0/obs-chzzk-alerts-0.5.0-windows-x64-setup.exe)

일반 사용자는 설치 파일을 권장합니다. ZIP 설치가 필요한 경우 아래의 접힌 수동 설치 안내를 펼쳐 주세요. 다운로드한 파일은 릴리스에 첨부된 `SHA256SUMS.txt`와 비교할 수 있습니다.

```powershell

```

## 필요한 프로그램

- Windows 10 또는 Windows 11 64비트
- OBS Studio 64비트
- Chrome 또는 Microsoft Edge
- 치지직 스트리머 스튜디오 리모컨을 사용할 수 있는 계정

OBS Live Editor도 사용한다면 반드시 `0.3.2` 이상으로 업데이트하세요. 이전 `0.3.1`과 함께 사용하면 연결 포트가 충돌합니다.

## 설치 및 업데이트

### 설치

1. OBS Studio를 완전히 종료합니다.
2. 내려받은 `setup.exe`를 실행합니다.
3. Windows 관리자 권한 요청을 승인합니다.
4. 설치가 끝나면 OBS를 실행합니다.

설치 프로그램은 권한 충돌을 방지하기 위해 OBS를 자동으로 실행하지 않습니다. 설치 완료 창을 닫은 뒤 OBS를 직접 실행해 주세요.

설치 파일은 아직 코드 서명되지 않아 Windows SmartScreen이 표시될 수 있습니다. GitHub 릴리스에서 받은 파일인지 확인하고, 필요한 경우 `추가 정보` → `실행`을 선택하세요.

### 업데이트

1. OBS Studio와 열려 있는 치지직 리모컨 탭을 종료합니다.
2. 최신 설치 파일을 내려받아 실행합니다.
3. 설치가 끝나면 확장 프로그램 관리 화면에서 `OBSChzzk 리모컨 이벤트 브리지`의 새로고침 버튼을 누릅니다.
4. OBS와 치지직 리모컨을 다시 실행합니다.

플러그인은 자동으로 다운로드하거나 설치하지 않습니다. 새 버전은 [최신 릴리스 페이지](https://github.com/TereBin/obs-chzzk-alerts-releases/releases/latest)에서 직접 확인합니다.

## 설정 방법

### 1. 브라우저 확장 프로그램 등록

Chrome은 주소창에 `chrome://extensions`, Edge는 `edge://extensions`를 입력합니다.

1. 오른쪽 위의 `개발자 모드`를 켭니다.
2. `압축해제된 확장 프로그램을 로드`를 누릅니다.
3. 다음 폴더를 선택합니다.

   ```text
   <OBS 설치 폴더>\data\obs-plugins\obs-chzzk-alerts\browser-relay
   ```

4. `OBSChzzk 리모컨 이벤트 브리지`가 활성화됐는지 확인합니다. `0.5.0` 패키지에 포함된 확장 프로그램 버전은 `0.2.2`입니다.

업데이트 후에는 확장 프로그램 관리 화면에서 새로고침 버튼을 누르고, 열려 있던 치지직 리모컨 탭도 새로고침해야 합니다.

### 2. OBS 알림 소스 추가

1. OBS의 `소스 목록`에서 `+`를 누릅니다.
2. `치지직 팔로우 알림`을 선택하고 새 소스를 만듭니다.
3. 기본 문구의 `{nickname}` 부분이 팔로워 닉네임으로 바뀝니다. 문구, 글꼴, 색상, 배경, 외곽선, 그림자와 정렬을 원하는 모양으로 조정합니다.
4. 이미지나 GIF를 함께 표시하려면 `이미지 / GIF`에서 `미디어 사용`을 켜고 파일을 선택합니다.
5. 미디어의 배치, 너비·높이, 텍스트와의 여백, 불투명도와 원본 비율 유지 여부를 조정합니다. 움직이는 GIF는 `알림마다 GIF 처음부터 재생`을 켜는 것을 권장합니다.
6. 소리를 함께 재생하려면 `알림 소리`에서 `알림 소리 사용`을 켭니다. `알림음 선택`에서 `기본 알림음 1·2·3` 중 하나를 고르거나 `사용자 파일`을 선택한 뒤 직접 준비한 음원을 지정합니다. 음량도 함께 조절합니다.
7. 표시 시간, 페이드 인·아웃 시간, 최대 대기열과 동일 닉네임 중복 방지 시간을 설정합니다.
8. `테스트 알림` 버튼을 눌러 방송 화면의 모양과 음원 재생을 확인한 뒤 소스의 크기와 위치를 조정합니다.

지원 형식은 OBS 이미지 소스가 지원하는 `BMP`, `TGA`, `PNG`, `JPEG`, `GIF`, `PSD`, `WebP`입니다. 배경 배치는 미디어 위에 텍스트와 텍스트 배경을 표시하므로, 배경 불투명도를 함께 조절하면 글자를 더 선명하게 만들 수 있습니다.

음원은 `MP3`, `WAV`, `OGG`, `AAC`, `M4A`, `FLAC`, `Opus` 등의 일반적인 형식을 사용할 수 있습니다. 방송 송출에는 기본적으로 포함되며, 방송 진행자가 직접 들으려면 OBS의 `고급 오디오 속성`에서 해당 소스의 오디오 모니터링을 설정하세요.

### 권장 기본 설정

처음에는 기본값을 그대로 사용한 뒤 방송 화면에 맞게 글꼴과 크기만 조정하는 것을 권장합니다.

- 소스 크기: `800 × 200`
- 미디어 크기: `160 × 160`
- 미디어 배치: `왼쪽`
- 텍스트와의 여백: `20`
- 미디어 불투명도: `100%`
- 알림 소리 음량: `100%`
- 표시 시간: `5초`
- 페이드 인·아웃: 각각 `300ms`
- 최대 대기 알림 수: `20`
- 같은 닉네임 중복 방지: `30초`

### 3. 사용 방법

1. OBS를 먼저 실행합니다.
2. 확장 프로그램을 등록한 Chrome 또는 Edge에서 치지직 스트리머 스튜디오의 `리모컨`을 엽니다. 일반 탭과 팝업 창 모두 사용할 수 있습니다.
3. 리모컨 탭을 열어 둔 상태로 방송합니다.
4. 새로운 사용자가 채널을 팔로우하면 OBS의 `치지직 팔로우 알림` 소스에 닉네임이 표시됩니다.

동일한 계정으로 언팔로우한 뒤 다시 팔로우하면 치지직 서버의 중복 처리 때문에 새 알림이 오지 않을 수 있습니다. 처음 팔로우하는 다른 계정으로 테스트하는 것이 가장 정확합니다.

## 제거

1. OBS Studio를 완전히 종료합니다.
2. Windows의 `설정 > 앱 > 설치된 앱`에서 `OBS Chzzk Alerts`를 제거합니다.
3. Chrome/Edge 확장 프로그램 관리 화면에서 `OBSChzzk 리모컨 이벤트 브리지`를 제거합니다.
4. OBS 소스 목록에 `치지직 팔로우 알림` 소스가 남아 있다면 직접 삭제합니다.

## 문제 해결

문제가 생기면 아래 순서로 확인하면 원인을 빠르게 구분할 수 있습니다.

1. OBS 소스 속성에서 `테스트 알림 표시`가 보이는지 확인합니다.
2. OBS 로그에 `[obs-chzzk-alerts] plugin loaded`가 있는지 확인합니다.
3. 설치한 버전에 동봉된 브라우저 확장 프로그램을 새로고침했는지 확인합니다.
4. 치지직 리모컨 탭을 새로고침합니다.
5. 처음 팔로우하는 다른 계정으로 실제 이벤트를 확인합니다.

### 리모컨에는 팔로우가 보이지만 OBS에는 표시되지 않음

- **확인:** OBS가 실행 중인지, `치지직 팔로우 알림` 소스가 현재 장면에 있고 보이도록 설정됐는지, 설치 버전에 동봉된 확장 프로그램이 활성화됐는지 확인합니다.
- **해결:** 알림 소스의 `테스트 알림`부터 확인합니다. 테스트는 보이지만 실제 팔로우만 보이지 않으면 확장 프로그램 관리 화면에서 확장 프로그램을 새로고침한 뒤 치지직 리모컨 탭도 새로고침합니다.

### 소리는 방송에 나오지만 내가 듣지 못함

1. `오디오 믹서`에서 `치지직 팔로우 알림`의 레벨 막대가 움직이는지 확인합니다.
2. `고급 오디오 속성`에서 해당 소스의 `오디오 모니터링`을 `모니터링 및 출력`으로 설정합니다.
3. OBS의 `설정 > 오디오 > 고급 > 모니터링 장치`에서 사용 중인 헤드폰이나 스피커를 선택합니다.

`모니터링만 (출력은 제거)`은 방송 출력에서 소리를 제외하므로, 방송과 본인 모두 들으려면 `모니터링 및 출력`을 사용하세요.

### 테스트 알림은 보이지만 믹서가 반응하지 않음

- 소스 속성의 `알림 소리 사용`을 켜고 알림음을 선택합니다. 사용자 파일이라면 파일이 실제로 존재하는지 확인합니다.
- 소스 음량과 믹서 음량이 0이 아닌지, 믹서가 음소거되지 않았는지 확인합니다.
- 최신 설치 파일로 업데이트한 뒤 OBS를 다시 실행해 `테스트 알림 표시`로 확인합니다.

### 치지직 리모컨에도 새 팔로우가 보이지 않음

- **확인:** 테스트 계정이 채널을 처음 팔로우하는 계정인지 확인합니다.
- **해결:** 동일 계정의 언팔로우 후 재팔로우는 치지직에서 중복 처리될 수 있습니다. 처음 팔로우하는 다른 계정으로 다시 테스트합니다.

### 개발자 도구에 `ERR_CONNECTION_REFUSED`가 표시됨

- **확인:** OBS가 실행 중인지 확인하고, `도움말 > 로그 파일 > 현재 로그 보기`에서 `[obs-chzzk-alerts] plugin loaded`를 검색합니다.
- **해결:** OBS를 완전히 종료한 뒤 최신 설치 파일을 다시 실행합니다. 설치 후 OBS를 먼저 실행하고 리모컨 탭을 새로고침합니다.

### OBS 로그에 포트 또는 플러그인 로드 오류가 표시됨

- **확인:** OBS Live Editor 버전이 `0.3.2` 이상인지 확인합니다. `0.3.1`은 동일한 `21345` 포트를 사용합니다.
- **해결:** OBS Live Editor를 `0.3.2` 이상으로 업데이트합니다. 문제가 계속되면 다른 프로그램이 포트를 사용 중인지 확인한 뒤 OBS를 다시 실행합니다.

### 확장 프로그램 폴더를 찾을 수 없음

- **확인:** 현재 사용 중인 OBS 설치 폴더의 `data\obs-plugins\obs-chzzk-alerts\browser-relay`에 확장 프로그램 파일이 있는지 확인합니다.
- **해결:** OBS를 완전히 종료하고 최신 설치 파일을 다시 실행합니다. 포터블 OBS는 현재 설치 프로그램이 자동으로 찾지 못할 수 있습니다.

### 설치 프로그램이 OBS를 찾지 못함

- **확인:** `<OBS 설치 폴더>\bin\64bit\obs64.exe`가 존재하는지 확인합니다.
- **해결:** 64비트 OBS Studio를 정식 설치 프로그램으로 설치한 뒤 OBS Chzzk Alerts 설치를 다시 시도합니다.

### OBS가 실행 중이라는 안내가 표시됨

- **확인:** 작업 표시줄, 시스템 트레이와 작업 관리자에서 `obs64.exe`가 남아 있는지 확인합니다.
- **해결:** OBS를 완전히 종료한 뒤 설치 파일을 다시 실행합니다.

문제가 계속되면 아래 [문제 보고](#문제-보고)를 참고해 이슈를 등록해 주세요.

## 개인정보와 소스 코드

팔로우 알림은 사용자 컴퓨터 안에서만 전달됩니다. 치지직 리모컨에서 확인한 닉네임을 `127.0.0.1`의 OBS 플러그인으로 전달하며 별도의 외부 서버에 저장하거나 전송하지 않습니다.

확장 프로그램은 치지직 스트리머 스튜디오 페이지에서 팔로우 이벤트를 감지합니다. 치지직 로그인 쿠키, WebSocket 인증값과 전체 이벤트 내용은 OBS로 전달하지 않습니다.

소스 코드, 기술 구조와 빌드 방법은 [obs-chzzk-alerts 소스 저장소](https://github.com/TereBin/obs-chzzk-alerts)에서 확인할 수 있습니다. OBS Chzzk Alerts는 GNU General Public License v2.0으로 배포됩니다.

WebSocket URL의 `auth` 값, 치지직 로그인 쿠키 또는 전체 HAR 파일은 공개 이슈나 Discord에 첨부하지 마세요.
